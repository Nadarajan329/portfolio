# Portfolio

A modern, responsive portfolio website built with React, Vite, and CSS.

## Features

- **Hero Section**: A visually stunning introduction.
- **About Me**: Brief background and information.
- **Experience**: Details of professional experience and achievements.
- **Projects**: Showcasing projects with links and descriptions.
- **Skills**: Technologies and tools used.
- **Contact**: A contact form.

## Tech Stack

- React 19
- Vite
- CSS (Vanilla)
- React Icons

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Build for production: `npm run build`
